# Data Structures and Algorithms (DSA)

A comprehensive collection of Data Structures and Algorithms implementations and practice problems using Python in Jupyter Notebooks.

## 📚 Repository Structure

```
DSA/
├── arrays/
│   └── array.ipynb
├── linkedlist/
│   └── linkedlist.ipynb
├── strings/
│   ├── string.ipynb
│   └── string_pattern.ipynb
└── other/
    ├── minimum.ipynb
    └── vigenier.ipynb
```

## 📖 Contents

### Arrays
- **array.ipynb**: Array data structure implementations, operations, and common problems

### Linked Lists
- **linkedlist.ipynb**: Linked list implementations and algorithms

### Strings
- **string.ipynb**: String manipulation algorithms and problems
- **string_pattern.ipynb**: String pattern matching algorithms and techniques

### Other
- **minimum.ipynb**: Minimum finding algorithms and related problems
- **vigenier.ipynb**: Vigenère cipher implementation

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yashwanth2706/DSA.git
cd DSA
```

2. Install Jupyter Notebook (if not already installed):
```bash
pip install jupyter
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

## 💡 Usage

Navigate to any directory and open the corresponding `.ipynb` file to explore implementations, explanations, and practice problems.
